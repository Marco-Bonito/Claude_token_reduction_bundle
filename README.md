# community-feedback (data branch)

This branch stores anonymous routing feedback from users of the `token-routing` plugin. Only GitHub Actions writes to it.

- `submissions/<contributor-id>.json`: the latest validated export of each contributor. A new export replaces the older one.
- `aggregate/report.md` and `aggregate/aggregate.json`: the weekly combined result.

How to contribute and what is shared: see `docs/community-feedback.md` on the `main` branch.
The data is published under the MIT license of the repository.
